`load/` (нагрузочный тест k6), `monitoring/` (Prometheus и Grafana), `.github/workflows/`
(тесты на GitHub Actions, решение 51).

## С чего начать

- **Посмотреть, как работает:** README, раздел «Запуск», затем [user-guide.md](user-guide.md).
- **Разобраться в коде:** [architecture.md](architecture.md), раздел «С чего начать читать»,
  затем [database.md](database.md).
- **Понять, почему так устроено:** [decisions.md](decisions.md); решения 15–19 задают границы
  подсистемы.
- **Подключить подсистему к системам страховой:**
  [integration-contract.md](integration-contract.md).
